# Life OS – Gentle Bloom 🌷

เว็บแอปจัดการชีวิตส่วนตัวภาษาไทย ธีม Pastel Kawaii ทำงานในเบราว์เซอร์โดยไม่ต้องติดตั้งแพ็กเกจ

## วิธีเปิดใช้งาน
1. แตกไฟล์ ZIP
2. เปิดไฟล์ `index.html` ด้วย Chrome, Edge, Safari หรือ Firefox
3. เริ่มเพิ่มงาน เป้าหมาย รายรับรายจ่าย บิล ยา นัดหมาย เอกสาร และบันทึกชีวิตได้เลย

## ฟีเจอร์
- Dashboard ภาพรวมชีวิตและรายการใกล้ถึงกำหนด
- Tasks, Goals, Projects, Habits
- Manifestation Goals, Affirmations, Gratitude Journal
- Finance: ธุรกรรม รายรับ/รายจ่าย บิล หนี้ เงินออม
- Health: บันทึกสุขภาพ ยา/วิตามิน นัดหมาย
- Learning, Personal Documents, Home & Lifestyle
- Journal, Review, Knowledge Library
- เพิ่ม/แก้ไข/ลบรายการ, ค้นหางาน, ติ๊กงานเสร็จ
- Export/Import ข้อมูลเป็น JSON เพื่อสำรองหรือย้ายเครื่อง

## ข้อมูลและความเป็นส่วนตัว
- ข้อมูลถูกเก็บใน Local Storage ของเบราว์เซอร์บนอุปกรณ์นี้
- ไม่มีบัญชีผู้ใช้, cloud sync, database server หรือการเชื่อมต่อธนาคาร
- หากล้างข้อมูลเว็บไซต์/เบราว์เซอร์หรือใช้โหมด Private ข้อมูลอาจหายได้ ควร Export JSON สำรองเป็นระยะ
- อย่าบันทึกรหัสผ่าน เลขบัตรประชาชนเต็มรูปแบบ หรือข้อมูลสุขภาพ/การเงินที่อ่อนไหวเกินจำเป็น
- เว็บนี้เป็นเครื่องมือจัดระเบียบชีวิต ไม่ใช่ระบบเวชระเบียนหรือคำแนะนำทางการแพทย์

## ถ้าต้องการเปิดเป็นเว็บไซต์ออนไลน์
อัปโหลด `index.html` ไปยังโฮสต์ static เช่น GitHub Pages, Netlify หรือ Cloudflare Pages ได้ แต่ก่อนใช้กับข้อมูลจริงควรวางแผนระบบล็อกอิน ฐานข้อมูลบนเซิร์ฟเวอร์ การเข้ารหัส การสำรองข้อมูล และการควบคุมสิทธิ์เข้าถึงก่อน
